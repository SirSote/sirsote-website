// Tools & Technologies

What I Work With

Each card is a tool on this machine and the job it does. Cursor writes the code. Vercel ships the sites. The rest is voice, video, data, or the lab.

Write and ship

Cursor

The editor for this site, Rick, Echo, and the vault. The agent sits in the same window as the file, so a change and the reason for it stay together.

VS Code

The other window on the same desk. Python, containers, and anything that is already open there stay in VS Code instead of being moved.

Claude Code

Terminal agent for a longer pass through a repo when the edit is bigger than one file in the editor.

Vercel

Deploys sirsote.com and the Echo frontend. The CLI is installed here so a local build and the live URL are the same project.

Git + GitHub

Public source for the website, Echo, Blaze, and Sote Choice. If it is not in a repo, it is still local.

Node

Runs the site, Echo (Next.js), WorldView (Vite), and Rick’s Remotion compositions.

Python

Rick’s voice and encode pipeline, Blaze’s publisher, WorldView’s API, and SpekFrst’s drill builder.

Obsidian

The .sote vault. SpekFrst’s method, agent runbooks, and the notes that have to stay true when the code changes.

draw.io

Architecture pictures for Echo and Blaze before the folders get confusing.

Voice, video, models

Claude API

Echo’s brain. A visitor describes a job and Claude turns that chat into a requirements draft.

Ollama

Local models on this box: Llama 3.1 8B, Llama 3.2 3B, and TinyLlama. Used when a script should not leave the machine.

OpenClaw

Local agent gateway. It is running on this PC so agents can talk to the machine without a hosted middleman.

Chatterbox

Rick’s voice. One recorded print, then new scripts spoken in that voice on CPU. No ElevenLabs account.

Piper

A plain local voice for layout tests and spoken drills, when the clone is more than the job needs.

faster-whisper

Times every word in Rick’s audio so Remotion can move the caption with the voice.

Remotion

Rick’s 9:16 picture, written in React. One clip at a time. This PC overheats if you render a batch.

FFmpeg

Turns the Remotion frame sequence into an H.264 reel Instagram can take.

ComfyUI

Local image generation on the AMD GPU through a ROCm Docker image. The t-shirt path is parked. Blaze’s job now is video.

OBS Studio

Screen capture when a project needs a recording of the desk, not a rendered clip.

Run it

Kali Linux

The daily OS. It is the host for Docker, the lab tools, and every project folder on this PC.

Docker

Keeps Mixpost, MariaDB, Redis, ComfyUI, PhoneInfoga, and pgAdmin off the host Python. Mixpost is the one that is up for Blaze.

Mixpost

Self-hosted scheduler. Blaze uses it to line up Rick’s reels. The Instagram reel upload is still the unfinished part.

PostgreSQL

Local database on this machine. DBeaver and pgAdmin are how it gets looked at. Echo’s hosted data is Supabase.

Supabase + Resend

Echo’s accounts and the email that leaves after an intake. They live with the Next.js app, not in a generic “API” bucket.

Next.js + Tailwind

Echo’s interface. The chat, the form, and the requirements page are this stack.

Vite + MapLibre

WorldView’s map. Open tiles, aircraft and satellite tracks, drawn in the browser.

FastAPI

WorldView’s small Python API: feeds for the map and a hook for a local model.

Proton VPN

The tunnel on this machine for lab traffic and ordinary browsing.

VirtualBox

Guest machines when a lab should not run on the host. The kernel module is missing right now, so guests are not starting.

Lab only

Wireshark + nmap

See the packets and map a network that you are allowed to look at. TryHackMe, Hack The Box, or a signed scope.

Ghidra

Read a binary in a lab. Installed here. Not a service.

Metasploit + Impacket

Practice techniques that already exist in a lab range. They are not a product and they are not pointed at anyone’s network.

Aircrack + Wifite

Wireless labs on gear you own or a range that says you may.

Hashcat + John

Work hashes that came from a lab capture, to learn how weak passwords fail.
